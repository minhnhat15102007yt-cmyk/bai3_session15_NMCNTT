Phần 1: Luồng dữ liệu (Từ Ctrl+S đến tích xanh)

  1. Ghi Local: Nhấn Ctrl+S →\rightarrow→ Lưu thẳng vào SSD (siêu nhanh, không cần mạng).

  2. Quét thay đổi: Ứng dụng Cloud phát hiện file thay đổi.

  3. Lọc dữ liệu (Bẫy node_modules): Hệ thống bỏ qua ngay các file rác trong node_modules (không đồng bộ chúng để tránh treo máy).

  4. Đẩy lên mây: Gửi các file code sạch (.js, .json) lên server Cloud.

  5. Hoàn tất: Nhận phản hồi thành công và hiện tích xanh.

Phần 2: Cấu trúc thư mục Cloud chuẩn

Plaintext

📁 MyStartupProject/
├── 📁 Code/          <-- Chỉ chứa mã nguồn & package.json (Đồng bộ, KHÔNG CÓ node_modules)
├── 📁 Docs/          <-- Tài liệu dự án (Dùng Files On-Demand: chỉ tải về khi cần)
└── 📁 Assets/        <-- Hình ảnh/video nặng (Dùng Files On-Demand: để sẵn trên mây)

Cách xử lý bẫy node_modules:

  • Tuyệt đối không đưa node_modules lên Cloud.

  • Khi sang máy mới, chỉ cần tải thư mục Code về rồi chạy lệnh npm install để máy tự sinh lại node_modules sạch sẽ.
